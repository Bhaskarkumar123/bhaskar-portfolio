CASE STUDY · 02

CUSTOMER CHURN PRIDICTION

This project focuses on predicting whether a customer will discontinue using a company’s services based on historical data. The goal is to help businesses proactively retain customers by identifying churn risks early.

The Idea

The idea behind the project is to use machine learning models to analyze customer behavior patterns — such as usage frequency, transaction history, and engagement metrics — and classify customers as “likely to churn” or “loyal.” It enables data-driven decision-making for marketing and retention strategies.

My Role

I worked on data preparation, feature engineering, model development and evaluation while comparing different machine learning approaches.

📈

Model Evaluation

Evaluating the models using appropriate prediction metrics to understand their performance.

Model Comparison

Multiple machine learning approaches were explored for the prediction task. Linear Regression and Random Forest were compared to understand which approach performed better on the prepared dataset.

Evaluation

For evaluation, the models were judged on how accurately they predicted churn, how well they balanced false positives and false negatives through precision and recall, how effectively they combined both with the F1 score and how clearly they distinguished churners from loyal customers using the ROC-AUC curve.
